Welcome to the source code of my personal portfolio website! I am **M. Alwan Farhan**, an Accessibility Specialist, Inclusive Designer, and Web Developer based in Surabaya, Indonesia. 

This website was built completely from scratch using **Vanilla HTML, CSS, and JavaScript**. No heavy frameworks, no bloated libraries. It is designed to be extremely lightweight, blazingly fast, and 100% accessible to all users.

## 🌟 Key Features
- **Accessible by Design**: fully compliant with WCAG 2.1 AA/AAA standards. Built-in screen reader support, semantic HTML, and full keyboard navigation.
- **Bilingual (ID/EN)**: Custom-built lightweight i18n engine allowing seamless switching between English and Indonesian without page reloads.
- **Dynamic Theming**: Fluid Light/Dark mode with automatic system preference detection.
- **Performance Optimized**: Lazy-loaded images (WebP/optimized JPGs), deferred scripts, and zero CSS frameworks to achieve a 100/100 Lighthouse score.
- **Contact Form Integration**: Fully functional serverless contact form via Formspree API with custom toast notifications.

## 🚀 Tech Stack
- **Structure**: Semantic HTML5
- **Styling**: Vanilla CSS3 (Custom Properties/Variables, Flexbox, CSS Grid, custom keyframe animations)
- **Logic**: Vanilla ES6 JavaScript (Fetch API, DOM manipulation, LocalStorage for state persistence)
- **Icons & Graphics**: FontAwesome, Lucide, Custom SVGs, Lottie Animations

## 🛠️ Installation & Local Development
Since this project does not rely on any bundlers (like Webpack or Vite), you don't need to run `npm install` or any build scripts to run it locally.

1. Clone this repository:
   ```bash
   git clone https://github.com/alwnfarhn-netizen/alwanfarhan.git
   ```
2. Open the project folder.
3. Simply launch a local server (e.g., using VS Code Live Server extension or Python `python -m http.server 3000`).
4. Open `http://localhost:3000` in your browser.
